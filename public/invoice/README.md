# Invoice assets

Inter 4.1 Regular, Medium and SemiBold are unmodified static TTF files from
https://github.com/rsms/inter/releases/tag/v4.1 (`extras/ttf/`).
Their SIL Open Font License is included in `INTER-LICENSE.txt`.

`capgo.png` is Capgo's existing invoice logo. These local assets are fetched only
when a PDF is downloaded and embedded into the PDF; no third-party font request
or customer data transfer is required.
