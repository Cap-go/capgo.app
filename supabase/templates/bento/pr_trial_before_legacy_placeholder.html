Example: legacy Bento "Trial" flow (not in repo)

Capgo sends org:legacy_stripe_trial_started on every Stripe customer.created. Bento automations use it for countdown and trial ending copy (for example "Halfway", "3 days left", "ends today", "trial ended", plus follow ups). Timing is fully in Bento, not in this repository.

Typical subjects (examples only, real copy is in Bento):

  • Trial: halfway
  • Trial: 3 days left
  • Trial: ends today
  • Trial ended

There is no HTML template file in this repo for those messages. This box is a before screenshot placeholder for PR documentation.
